# Testing and Troubleshooting

Welcome to the Testing and Troubleshooting section. 

Building reliable software for maritime safety means we cannot afford to guess if things are working. This section covers how we test the entire MvuviGo ecosystem, from manual API tests to automated end-to-end browser testing and our GitHub Actions CI pipelines.

* **[Frontend Build](/testing/frontend-build)** - How our GitHub Actions pipelines check modified files, lint code, and run Playwright/Cypress tests.
* **[Postman Examples](/testing/postman-examples)** - How to manually test API endpoints using Postman.
* **[Common Issues](/testing/common-issues)** - Solutions to frequent problems you might encounter during local development.
